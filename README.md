**Student:** Anshika Verma

**University:** Shri Ramswaroop Memorial University, Lucknow

## Project Overview
This project extends the personal portfolio with JavaScript functionality. It demonstrates client-side scripting, DOM manipulation, functions, event listeners, form validation, interactive elements and Local Storage.

## Implemented Features
- Dark/Light mode toggle
- Local Storage for theme preference
- Mobile navigation menu
- Clickable skills with dynamic DOM messages
- Project Show Details interaction
- Interactive image slider
- Contact form validation with error messages
- Reusable validation functions
- Scroll-to-top button

## Required File Structure
```text
index.html
style.css
script.js
README.md
images/
```

## Setup
1. Download/clone the repository.
2. Open the folder in VS Code.
3. Open `index.html` in a modern browser.
4. Keep all files and the images folder in the same structure.

## JavaScript Concepts
- Variables: `const`, `let`
- Functions: reusable functions for theme, slider and validation
- DOM: `getElementById`, `querySelectorAll`, `classList`, `textContent`
- Events: click and submit listeners
- Validation: name, email and message checks
- Local Storage: theme preference
- Dynamic content: skills, projects and gallery
- Added interactive features including theme toggling with 'localStorage',an image slider and dynamic skill message displays
